Error: 'dict' object has no attribute 'decode'

Fix:
Update your subprocess FFmpeg call to avoid decoding stderr or stdout when it's already a string or not required. Here’s how:

python
Copy
Edit
import subprocess

result = subprocess.run(
    ffmpeg_command,
    stdout=subprocess.PIPE,
    stderr=subprocess.PIPE,
    text=True  # Ensures output is string, so no .decode() needed
)

if result.returncode != 0:
    print("FFmpeg error:", result.stderr)
Ensure you remove any .decode() calls on result.stdout or result.stderr.

ECONNREFUSED errors from Chrome extension

Fix:

Ensure Flask server is listening on 0.0.0.0 and not just 127.0.0.1:

python
Copy
Edit
app.run(host="0.0.0.0", port=5000)
In the frontend, access the server using http://localhost:5000 (or your IP if not hosted locally).

If using HTTPS in your extension or webpage, ensure your server supports it or force everything to HTTP for dev.
